An authenticated workspace member can exploit the strict_mode bypass by targeting workspace-audience bundles with crafted relative file names containing traversal segments. Because ArchiveService sets strict_mode=False for non-OPS bundles, the StorageGateway._resolve_path() method skips the PathValidator.safeguard() check when the file name is not in known_entries. This allows the caller to read drafts, ops notes, or another workspace's export files that sit outside the intended bundle directory.
