An authenticated workspace member can exploit the conditional validation bypass by targeting non-OPS bundles (codes that do not contain "OPS") with crafted relative file names containing traversal segments. Because ArchiveService passes an empty known_entries tuple for non-OPS bundles, the StorageGateway._resolve_path() method skips the PathValidator.safeguard() check and joins the user-controlled name directly to the bundle root. This allows the caller to read drafts, ops notes, or another workspace's export files that sit outside the intended bundle directory.
